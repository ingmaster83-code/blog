## 주요 기능 — 실무에서 바로 쓰는 단축키 카테고리

### 창 배치와 화면 분할

윈도우11에서 가장 체감이 큰 영역이다. Win + 화살표로 창을 좌우 절반에 붙이고, Win + Z로 스냅 레이아웃을 띄워 3분할·4분할 배치를 마우스 없이 지정한다. 모니터 두 대를 쓰는 사람이라면 Win + Shift + 화살표로 창을 다른 모니터로 즉시 넘기는 키부터 익히는 게 좋다.

### 파일 탐색기와 폴더 작업

Ctrl + Shift + N으로 새 폴더를 만들고, Alt + 위쪽 화살표로 상위 폴더로 이동한다. F2로 이름 바꾸기, Ctrl + Shift + E로 선택 항목의 상위 경로를 펼치는 기능은 대량 파일 정리할 때 시간 차이가 크다.

### 가상 데스크톱과 작업 전환

Win + Ctrl + D로 새 데스크톱을 만들고, Win + Ctrl + 좌우로 화면을 넘긴다. 업무용·개인용·회의용을 분리해 두면 Alt + Tab 목록이 짧아져 전환 속도가 눈에 띄게 올라간다.

### 텍스트 편집과 브라우저

Ctrl + Backspace로 단어 단위 삭제, Shift + Home/End로 줄 선택, Ctrl + Shift + T로 방금 닫은 브라우저 탭 복구. 문서 작업과 웹 리서치를 오가는 직군에서 반복 사용 빈도가 가장 높은 조합이다.

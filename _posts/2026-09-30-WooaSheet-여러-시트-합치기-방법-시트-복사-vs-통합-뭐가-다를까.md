## 여러 시트 합치기, 왜 매번 손이 멈칫할까

WooaSheet 여러 시트 합치기 방법을 찾는 사람 대부분은 이미 한 번쯤 실패를 겪은 경우가 많습니다. 예를 들어 지점별 매출 시트 12개를 하나로 모으려는데, 어떤 시트는 열 순서가 다르고 어떤 시트는 중간에 빈 행이 끼어 있습니다. 복사해서 붙여넣기만 반복하면 오전이 그냥 사라집니다.

이 글에서는 시트를 합치는 두 가지 접근, 즉 시트 복사 방식과 통합 방식의 차이를 비교하고, 브라우저에서 바로 쓸 수 있는 [WooaSheet 무료로 사용하기](https://wooasheet.wooahouse.com) 기능을 실무 관점에서 정리합니다.

## 시트 복사 vs 데이터 통합, 무엇이 다른가

### 시트 복사 방식

원본 시트를 그대로 다른 파일로 옮기는 방식입니다. 서식, 수식, 조건부 서식까지 살아 있지만, 시트마다 구조가 다르면 결과물도 뒤죽박죽이 됩니다. 같은 양식으로 작성된 월별 보고서처럼 구조가 동일할 때만 유효합니다.

### 데이터 통합 방식

헤더(열 이름)를 기준으로 값만 뽑아 하나의 표로 재구성하는 방식입니다. 열 순서가 달라도 맞춰지고, 필요 없는 열은 제외할 수 있습니다. 대신 서식은 사라지고 값 중심으로 합쳐진다는 점을 감안해야 합니다.

정리하면 이렇습니다.

- 양식이 100% 동일하다 → 시트 복사
- 열 순서·구성이 제각각이다 → 데이터 통합
- 수식 결과값만 필요하다 → 데이터 통합
- 서식까지 그대로 유지해야 한다 → 시트 복사

## WooaSheet에서 여러 시트 합치는 순서

### 1단계: 파일 불러오기

CSV, XLSX 파일을 브라우저로 끌어다 놓습니다. 여러 개를 한 번에 올릴 수 있고, 설치 과정은 없습니다.

### 2단계: 헤더 행 지정

각 파일에서 몇 번째 행이 열 이름인지 지정합니다. 첫 행이 제목이고 두 번째 행부터 데이터가 시작되는 경우가 많으므로, 미리보기로 확인한 뒤 지정하는 편이 안전합니다.

### 3단계: 열 매핑 확인

자동으로 열 이름을 매칭해주지만, 이름이 살짝 다른 열은 직접 연결해야 합니다. 예를 들어 A 파일의 "매출액"과 B 파일의 "매출"은 자동으로 붙지 않습니다.

### 4단계: 결과 확인 후 내보내기

합쳐진 표를 미리 보고, 빈 행이나 중복 행이 있으면 정리한 뒤 CSV나 XLSX로 저장합니다.

## 실제로 써보니 달랐던 점

지점 9곳의 월간 실적 시트를 합치는 작업에 적용해봤습니다. 가장 도움이 된 건 열 매핑 단계였습니다. 지점마다 담당자가 양식을 조금씩 다르게 만들어둔 상태였는데, 열 이름 기준으로 정리되니 수작업으로 순서를 바꿀 필요가 없었습니다.

반대로 아쉬웠던 부분도 있습니다. 셀 배경색이나 글꼴 같은 서식은 결과물에 남지 않습니다. 보고용으로 예쁘게 꾸며야 한다면 합친 뒤 다시 서식을 입히는 과정이 필요합니다. 또한 헤더 이름에 오타가 있으면 자동 매칭이 안 되므로, 합치기 전에 열 이름 정도는 점검해두는 게 시간을 아낍니다.

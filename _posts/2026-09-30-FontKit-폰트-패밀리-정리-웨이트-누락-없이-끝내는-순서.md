## 폰트 패밀리 정리 방법, 왜 굵기별로 흩어지는가

디자이너나 퍼블리셔라면 한 번쯤 겪는 상황이 있습니다. 같은 글꼴을 Regular, Bold, Light, Medium으로 받아놨는데 파일 이름이 제각각이라 CSS에서 굵기를 바꿔도 화면이 그대로인 경우입니다. 폰트 패밀리 정리 방법을 모르면 파일 하나하나 열어보며 이름을 손으로 고치는 수밖에 없습니다.

이 글에서는 브라우저에서 바로 쓸 수 있는 도구 하나를 기준으로, 흩어진 폰트 파일을 패밀리 단위로 묶는 순서를 정리합니다. 장점만 나열하지 않고 실제로 걸리는 지점도 함께 짚습니다.

## FontKit 첫 소개와 접속

[FontKit 무료로 사용하기](https://fontkit.wooahouse.com)는 폰트 파일을 업로드 없이 브라우저에서 다루는 웹 도구입니다. 별도 설치나 회원가입 없이 주소만 열면 바로 시작됩니다.

핵심은 폰트 패밀리 관리입니다. 같은 글꼴의 여러 웨이트를 하나의 패밀리로 묶고, 이름 규칙을 통일한 뒤 미리보기로 확인하는 흐름이 한 화면에서 끝납니다.

### 어떤 파일을 지원하나

TTF, OTF, WOFF, WOFF2 계열을 다룹니다. 웹에 올릴 용도라면 WOFF2, 데스크톱 설치용이라면 TTF나 OTF를 기준으로 정리하면 됩니다.

## 기능 상세: 패밀리 묶기부터 이름 통일까지

### 1단계 폰트 파일 불러오기

정리하려는 폰트 파일을 한 번에 여러 개 선택합니다. 같은 글꼴의 Light, Regular, Medium, Bold, Black을 모두 넣는 것이 좋습니다. 하나라도 빠지면 나중에 패밀리 안에서 굵기가 비는 구간이 생깁니다.

### 2단계 웨이트 자동 인식 확인

도구가 파일 메타데이터를 읽어 굵기를 추정합니다. 다만 파일명이 `font-bold-final-2.ttf`처럼 뒤죽박죽이면 인식이 어긋날 수 있습니다. 이 경우 직접 웨이트 값을 지정해줍니다.

### 3단계 패밀리 이름 통일

가장 중요한 단계입니다. `Pretendard-Regular`, `Pretendard Bold`, `pretendard_bold`처럼 표기가 제각각이면 브라우저는 서로 다른 폰트로 봅니다. 패밀리 이름을 하나로 고정하고, 각 파일에는 웨이트만 다르게 붙입니다.

### 4단계 미리보기 검수

정리된 패밀리를 문장 샘플로 미리 봅니다. 한글, 영문, 숫자를 함께 넣어 굵기 전환이 자연스러운지 확인합니다. 이 단계를 건너뛰면 실제 사이트에 적용한 뒤에야 어색한 구간을 발견하게 됩니다.

## 실제 사용 후기: 좋았던 점과 아쉬운 점

### 좋았던 점

- 설치 없이 브라우저에서 끝난다는 점이 가장 실용적입니다. 회사 PC에 프로그램을 깔 수 없는 환경에서도 작업이 됩니다.
- 여러 웨이트를 한 번에 넣고 이름만 통일하는 방식이라, 파일을 하나씩 열어 메타데이터를 고치는 것보다 손이 덜 갑니다.
- 미리보기가 즉시 반영되어 시행착오 비용이 낮습니다.

### 아쉬운 점

- 폰트 파일 자체의 내부 메타데이터를 영구적으로 다시 쓰는 작업은 아니므로, 배포용 파일을 만들려면 별도 저장 절차를 거쳐야 합니다.
- 웨이트 자동 인식이 100% 정확하지는 않습니다. 파일명이 지저분하면 수동 지정이 필수입니다.
- 폰트가 수십 개로 늘어나면 화면에서 원하는 파일을 찾는 데 시간이 걸립니다. 미리 패밀리별로 폴더를 나눠두는 편이 낫습니다.

## 폰트 패밀리 정리에서 자주 나오는 실수

### 이름 규칙을 중간에 바꾸는 것

작업 도중 `Pretendard`를 `PretendardGothic`으로 바꾸면 앞서 묶은 파일과 따로 놀게 됩니다. 시작 전에 최종 이름을 정하고 끝까지 유지하는 편이 안전합니다.

### 웨이트 값을 건너뛰는 것

Light(300), Regular(400), Bold(700)만 있고 Medium(500)이 없으면, CSS에서 500을 요청할 때 브라우저가 임의로 다른 굵기를 대체합니다. 의도한 결과가 나오지 않는 흔한 원인입니다.

### 이탤릭을 같은 패밀리로 착각하는 것

이탤릭은 별도 스타일 축입니다. 패밀리 이름은 같아도 스타일 구분이 없으면 브라우저가 기울임을 합성해 흐릿하게 보일 수 있습니다.

## 마무리: 순서만 지키면 5분이면 끝납니다

폰트 패밀리 정리 방법의 핵심은 파일을 한 번에 모아 넣고, 웨이트를 확인하고, 이름을 하나로 고정한 뒤 미리보기로 검수하는 네 단계입니다. 이 순서를 지키면 굵기 누락이나 이름 불일치로 생기는 재작업을 크게 줄일 수 있습니다.

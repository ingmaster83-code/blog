## 주요 기능 4가지

### 1. 자동 정렬과 구문 강조

한 줄로 뭉친 JSON을 붙여넣으면 들여쓰기가 자동 적용되고, 키·문자열·숫자·불리언이 색으로 구분됩니다. 눈으로 괄호 짝을 세는 작업이 사라집니다.

### 2. 트리 접기와 펼치기

중첩 깊이 100단계까지 노드를 접을 수 있어, 응답이 3,000줄이어도 필요한 분기만 열어보면 됩니다. 배열 인덱스와 객체 키 경로가 함께 표시되어 원하는 값을 역추적하기 쉽습니다.

### 3. 오류 위치 즉시 표시

쉼표 누락, 따옴표 불일치, 후행 콤마 같은 흔한 실수를 줄 번호와 함께 짚어줍니다. 유효성 검사를 통과하지 못한 지점을 찾느라 앞부분을 반복해서 훑을 필요가 없습니다.

### 4. 복사·다운로드 한 번에

정렬된 결과를 그대로 복사하거나 파일로 내려받을 수 있어, 코드에 다시 붙여넣는 과정이 단순해집니다.

## 실무에서 바로 쓰는 활용 팁

### API 응답 디버깅 순서

응답 전문을 붙여넣기 → 오류 표시 확인 → 루트 노드부터 접기 → 문제 분기만 펼치기. 이 순서를 지키면 1MB 이하 응답은 대부분 1분 안에 원인 지점에 도달합니다.

### 설정 파일 비교할 때

`package.json`, `tsconfig.json`처럼 키 순서가 뒤섞인 파일은 정렬 후 복사해두면 diff 도구에서 실제 변경점만 남습니다. 포맷 차이 때문에 생기는 가짜 변경이 사라지는 효과가 큽니다.

### 로그에서 특정 값 찾기

브라우저 내장 검색(Ctrl+F)과 트리 접기를 조합하면, 수천 줄 로그에서 특정 키만 빠르게 추려낼 수 있습니다. 접힌 노드 안쪽은 검색 대상에서 빠지므로 먼저 전부 펼친 뒤 검색하는 것이 요령입니다.

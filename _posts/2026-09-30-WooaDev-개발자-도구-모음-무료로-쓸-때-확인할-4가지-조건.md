## 개발자 도구 모음 무료로 찾다가 지친 이유

급하게 JSON 응답을 예쁘게 정리해야 하는데, 즐겨찾기해둔 사이트가 광고 팝업으로 뒤덮여 있었다. 다른 탭에서는 회원가입을 요구하고, 또 다른 곳은 하루 3회 제한을 걸어둔다. 결국 검색을 다시 하는 데 10분을 썼다. 개발자 도구 모음 무료 서비스를 찾을 때 진짜 문제는 "무료인가"가 아니라 "무료라는 말이 어디까지를 뜻하는가"다.

원인은 단순하다. 대부분의 온라인 도구는 서버에서 연산을 처리한다. 서버 비용이 발생하니 횟수 제한, 회원가입, 유료 티어가 붙는다. 반면 브라우저 자체 성능으로 처리하는 도구는 이런 제약이 필요 없다. 판단 기준이 "서버를 쓰는가, 안 쓰는가" 하나로 갈리는 이유다.

## WooaDev 소개 — 설치 없이 브라우저에서 끝나는 도구 모음

[WooaDev 무료로 사용하기](https://wooadev.wooahouse.com)는 이 구조를 정면으로 택한 사이트다. 회원가입도, 설치도, 횟수 제한도 없다. 접속하면 도구 목록이 바로 뜨고, 파일을 넣으면 브라우저 안에서 처리된다.

확인해야 할 조건은 다음 네 가지다.

### 1. 처리 위치가 로컬인가

파일을 넣었을 때 네트워크 탭에 업로드 요청이 찍히는지 보면 된다. WooaDev는 파일 선택 자체는 사용자 디스크에서 읽고, 연산은 자바스크립트 엔진이 담당한다. 즉 민감한 로그 파일이나 사내 문서를 다뤄도 외부로 나가지 않는다.

### 2. 도구 간 이동이 끊기지 않는가

개발 작업은 한 도구로 끝나지 않는다. JSON을 정리하고, 그 결과를 텍스트로 변환하고, 다시 비교한다. WooaDev는 이런 흐름을 한 사이트 안에서 이어갈 수 있게 도구를 묶어뒀다. 탭을 오가며 새 사이트에 파일을 다시 올리는 왕복이 사라진다.

### 3. 결과물에 워터마크나 제한이 없는가

무료 도구의 함정은 결과물이다. 텍스트 변환 결과에 안내 문구가 붙거나, 이미지에 로고가 들어가거나, 복사 버튼이 잠기는 경우가 많다. WooaDev는 결과를 그대로 복사·다운로드할 수 있다.

### 4. 오프라인에서도 버티는가

한 번 페이지를 로드한 뒤에는 네트워크가 끊겨도 대부분의 변환 작업이 돌아간다. 서버 왕복이 없기 때문이다. 비행기나 보안망 안에서 급하게 텍스트를 정리해야 할 때 체감 차이가 크다.

## 실제 사용 후기 — 3주 써보고 남은 것

가장 자주 쓴 건 텍스트 계열 도구였다. API 응답 로그를 붙여넣고 정리하는 작업, 마크다운 표를 정렬하는 작업, 두 파일의 차이를 비교하는 작업을 한 탭에서 처리했다. 예전에는 사이트 세 개를 즐겨찾기해두고 상황에 따라 골라 썼는데, 그 북마크 폴더를 이제 안 연다.

아쉬운 점도 있다. 브라우저 메모리를 쓰는 구조라 100MB가 넘는 파일을 넣으면 처리 속도가 눈에 띄게 떨어진다. 이런 경우는 파일을 분할하거나 데스크톱 도구를 쓰는 게 낫다. 또 도구 수가 아주 많은 편은 아니라서, 특수한 포맷 변환이 필요하면 다른 곳을 찾아야 한다.

그래도 "급할 때 30초 안에 열어서 끝내는" 용도로는 이만한 조합을 못 찾았다. 개발자 도구 모음 무료 서비스를 고를 때 광고와 제한을 먼저 따지는 습관이 있다면, 처리 위치부터 확인해보길 권한다.

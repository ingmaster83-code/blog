## 개발 JSON CSV 변환, 매번 손으로 하다 지치지 않았나요

개발 JSON CSV 변환 작업은 API 응답을 엑셀로 확인하거나, 로그 데이터를 분석하거나, DB 시드 파일을 만들 때 빠지지 않고 등장합니다. 그런데 매번 파이썬 스크립트를 짜거나 온라인 변환기를 찾아 헤매다 보면 시간이 훅 지나가 버립니다. 특히 사내 데이터를 외부 사이트에 올리는 순간 보안 이슈가 생기죠. 이 글은 그런 문제를 겪는 개발자를 위한 실전 해결 가이드입니다.

원인은 크게 세 가지입니다. 첫째, JSON은 계층 구조라서 CSV의 평면 표 형태로 바꾸려면 중첩 객체를 펼치는 로직이 필요합니다. 둘째, 배열 길이가 제각각이면 컬럼 정의가 애매해집니다. 셋째, 기존 온라인 도구는 대부분 파일을 서버로 업로드하는 구조라 민감 데이터에 부담이 됩니다. 결국 "간단한 변환 하나 때문에" 코드를 새로 짜는 상황이 반복됩니다.

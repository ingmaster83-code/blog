## 설치형 편집기와 온라인 도구, 갈리는 지점

### 설치형 XML 편집기의 강점과 부담

전용 편집기는 스키마 검증, XSLT 변환, 대용량 스트리밍 처리까지 지원 범위가 넓습니다. 다만 설치 용량이 수백 MB에 달하고, 라이선스 등급에 따라 일부 기능이 잠깁니다. 회사 보안 정책상 임의 설치가 막힌 환경이라면 시작 자체가 어렵습니다.

### 무료 온라인 XML 변환 도구의 조건

반대로 브라우저 도구는 설치 없이 열리고, 파일을 끌어다 놓으면 끝나는 흐름이 대부분입니다. 문제는 도구마다 처리 방식이 제각각이라는 점입니다. 어떤 곳은 파일을 서버로 올려 변환하고, 어떤 곳은 브라우저 메모리 안에서만 처리합니다. 이 차이가 보안과 속도를 동시에 바꿉니다.

## 확인할 4가지 체크리스트

### 1. 파일이 서버로 전송되는가

가장 먼저 볼 항목입니다. 서버 업로드 방식은 사내 문서나 고객 데이터가 담긴 XML에는 맞지 않습니다. 브라우저 내 처리 방식이면 네트워크 탭에 업로드 요청이 남지 않습니다. 민감한 설정 파일을 다룬다면 이 조건만으로 후보가 절반으로 줄어듭니다.

### 2. XML to JSON, CSV 등 출력 형식 범위

변환 대상이 XML 하나뿐이라면 상관없지만, 실무에서는 JSON이나 CSV로 함께 뽑아야 할 때가 많습니다. 도구를 옮겨 다니면 들여쓰기 규칙이 달라져 후처리 코드를 다시 손봐야 합니다. 한 화면에서 형식을 바꿔가며 결과를 비교할 수 있으면 이 반복이 사라집니다.

### 3. 결과물 복사·저장 방식

미리보기만 보여주고 복사 버튼을 숨겨두는 도구가 있습니다. 저장하려고 화면을 긁어오면 공백과 줄바꿈이 섞여 들어가 파서가 다시 걸립니다. 복사, 파일 저장, 클립보드 내보내기가 모두 열려 있는지 확인하세요.

### 4. 인코딩과 네임스페이스 처리

한글 주석이 든 XML을 변환했더니 글자가 깨지는 경우는 대부분 UTF-8 선언을 도구가 무시해서 생깁니다. 네임스페이스 접두사를 임의로 바꿔버리는 도구도 있어, 원본 구조를 그대로 유지하는지 결과를 나란히 놓고 봐야 합니다.

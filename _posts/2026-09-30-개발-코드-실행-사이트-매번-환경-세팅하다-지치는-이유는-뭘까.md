## 주요 기능 상세

### 에디터와 실행 화면이 한 페이지에

코드를 입력하는 영역과 결과가 출력되는 영역이 나란히 배치되어 있다. 실행 버튼을 누르면 새 탭으로 넘어가지 않고 같은 화면에서 결과가 갱신된다. 문법 강조와 줄 번호 표시가 기본으로 들어가 있어 가독성도 크게 떨어지지 않는다.

### 언어별 실행 방식

HTML, CSS, JavaScript 조합은 작성한 그대로 렌더링 결과를 확인할 수 있어 마크업 구조나 스타일 조정에 적합하다. 파이썬 코드 역시 브라우저 안에서 실행되며, 콘솔 출력으로 결과를 확인하는 방식이다. 서버가 필요한 백엔드 프레임워크나 외부 데이터베이스 연동은 지원 범위 밖이라는 점을 미리 알아두면 헛걸음이 줄어든다.

### 오류 메시지 확인

실행 중 에러가 나면 출력 영역에 메시지가 그대로 표시된다. 예외 처리 코드를 넣었다 빼면서 동작을 비교하기 좋다. 로그를 파일로 남길 필요 없이 화면에서 바로 읽고 고칠 수 있다는 게 실무에서 체감되는 차이다.

## 실제로 써보면

필자가 가장 자주 쓰는 상황은 두 가지다. 첫째, 외부 라이브러리 없이 순수 로직만 검증할 때. 알고리즘 문제를 풀거나 정규식 패턴이 제대로 걸리는지 확인할 때 로컬 편집기를 켤 이유가 사라진다. 둘째, 다른 사람에게 코드를 보여줄 때. 링크 하나로 공유하면 상대방이 환경을 맞출 필요 없이 같은 결과를 본다.

반대로 아쉬운 지점도 분명하다. 대용량 프로젝트를 통째로 돌리기엔 맞지 않고, 파일 시스템 접근이 필요한 코드는 실행할 수 없다. 즉 "가볍게 확인하는 용도"에 최적화되어 있다고 보면 된다. 이 경계만 알고 쓰면 불필요한 시행착오를 크게 줄일 수 있다.

## HEX, RGB, HSL을 한 화면에서 동시에 보는 구조

### 색상 코드 3종 즉시 변환

가장 자주 쓰는 기능은 HEX ↔ RGB ↔ HSL 왕복 변환입니다. 값을 입력하면 나머지 두 형식이 실시간으로 갱신됩니다. 예를 들어 `#FF6B35`를 넣으면 `rgb(255, 107, 53)`과 `hsl(16, 100%, 60%)`가 동시에 표시됩니다. CSS 색상 변환이 필요한 이유는 상황마다 요구하는 형식이 다르기 때문입니다. 투명도를 넣으려면 RGBA, 채도만 조정하려면 HSL이 편합니다.

### 슬라이더로 색감 미세 조정

숫자만 입력하는 방식이 아니라 색상환과 채도·명도 슬라이더로 직접 움직일 수 있습니다. 마우스로 조금씩 당기면서 "이 정도면 로고랑 붙겠다" 싶은 지점을 찾는 식입니다. 개발자도구를 열어 실시간으로 확인하는 것보다 이 방법이 훨씬 빠릅니다.

### 그라디언트 코드 추출

배경에 그라디언트를 넣어야 할 때 두 개 이상의 색상을 지정하면 `linear-gradient` CSS 코드를 그대로 복사할 수 있습니다. 각도 조절도 가능해서 `135deg` 방향까지 세팅한 뒤 붙여넣기만 하면 됩니다. 별도로 그라디언트 계산기를 찾을 필요가 없습니다.

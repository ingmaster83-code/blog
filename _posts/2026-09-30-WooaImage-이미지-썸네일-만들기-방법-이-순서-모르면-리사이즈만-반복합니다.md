## WooaImage 이미지 썸네일 만들기 방법, 순서만 바꿔도 30초가 5초가 됩니다

블로그에 글 하나 올리려다 썸네일 크기 맞추느라 30분을 날린 적 있으신가요. 캡처 → 그림판 → 리사이즈 → 저장 → 다시 열어보기 → 잘림 확인, 이 루프를 세 번 돌면 정작 글 쓸 시간이 사라집니다. 오늘 다룰 **WooaImage 이미지 썸네일 만들기 방법**은 이 루프를 한 화면에서 끝내는 순서에 관한 이야기입니다.

### 도구 소개

[WooaImage 무료로 사용하기](https://imagekit.wooahouse.com)는 별도 설치나 회원가입 없이 브라우저에서 바로 열리는 이미지 편집 도구입니다. 핵심은 "편집 → 저장 → 다시 확인"이 아니라 "설정 → 미리보기 → 저장"으로 흐름이 바뀐다는 점입니다. 파일 선택 단계부터 결과물이 화면에 즉시 반영되기 때문에, 저장 후 다시 열어보는 헛수고가 사라집니다.

### 주요 기능

#### 1. 크기·비율 동시 지정
가로만 입력하면 세로가 자동 계산되는 비율 고정 모드가 있습니다. 썸네일에서 가장 흔한 실수가 가로세로를 따로 넣다가 비율이 틀어지는 것인데, 이 옵션 하나로 그 문제가 사라집니다.

#### 2. 실시간 미리보기
값을 바꿀 때마다 결과가 즉시 갱신됩니다. "저장하고 나서 잘렸네"를 사전에 막는 게 업무 효율에서 가장 큰 차이를 만듭니다.

#### 3. 포맷·품질 조정
JPG, PNG, WebP 중 선택할 수 있고 품질 슬라이더로 용량을 조절합니다. 블로그 썸네일은 WebP로 80~90 품질이면 원본 대비 절반 이하 용량으로도 육안 차이가 거의 없습니다.

#### 4. 드래그 앤 드롭
파일을 끌어다 놓으면 바로 편집 화면으로 넘어갑니다. 폴더를 여는 단계 자체가 줄어듭니다.

### 활용 팁

**첫째, 원본은 절대 덮어쓰지 마세요.** 리사이즈 결과를 같은 파일명으로 저장하면 원본이 사라집니다. 파일명 뒤에 `_thumb`을 붙이는 습관만으로 되돌릴 수 있는 여지가 생깁니다.

**둘째, 플랫폼별 규격을 먼저 확인하세요.** 네이버는 1200px 내외, 티스토리는 1200x630px, 유튜브 썸네일은 1280x720px입니다. 규격을 모른 채 작업하면 같은 이미지를 세 번 다시 만드는 상황이 옵니다.

**셋째, 용량은 마지막에 줄이세요.** 크기 조정 → 텍스트 배치 → 포맷 변환 순서로 가야 합니다. 순서를 뒤집으면 압축된 이미지 위에 텍스트를 얹다가 계단 현상이 생깁니다.

**넷째, 여러 장은 규격을 통일하세요.** 썸네일 크기가 제각각이면 목록 페이지에서 정렬이 깨져 보입니다. 한 번 정한 픽셀 값을 메모해 두고 재사용하는 편이 결국 빠릅니다.

### 마무리

정리하면 **WooaImage 이미지 썸네일 만들기 방법**의 핵심은 도구를 바꾸는 게 아니라 순서를 바꾸는 것입니다. 원본 보존 → 규격 확인 → 크기 조정 → 포맷 변환, 이 네 단계만 지켜도 썸네일 작업 시간이 눈에 띄게 줄어듭니다. 무엇보다 브라우저 안에서 모든 처리가 끝나니 보안 걱정 없이 쓸 수 있다는 게 실무에서 의외로 큰 장점입니다.

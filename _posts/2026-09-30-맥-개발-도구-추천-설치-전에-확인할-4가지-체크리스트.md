## 맥 개발 도구 추천, 새 맥북 받은 날 가장 먼저 하는 일

## 체크리스트 1 — 칩 아키텍처와 빌드 호환성

### Apple Silicon인지 Intel인지 먼저 본다
- 상단 메뉴 → 이 Mac에 관하여에서 칩 종류를 확인합니다.
- arm64 전용 빌드가 없는 도구는 Rosetta 2로 실행해야 하므로, 터미널 명령어 일부가 느려질 수 있습니다.
- Homebrew는 `/opt/homebrew`(Apple Silicon)와 `/usr/local`(Intel) 경로가 달라, 기존 설정 파일을 그대로 복사하면 깨집니다.

### 개발 언어 런타임 버전 관리
Node, Python, Ruby를 시스템 기본 버전으로 쓰면 프로젝트마다 충돌이 납니다. nvm, pyenv, rbenv 같은 버전 관리자를 먼저 깔고 프로젝트별로 고정하는 편이 이후가 편합니다.

## 체크리스트 2 — 터미널과 셸 환경

### iTerm2 + Oh My Zsh 조합
기본 Terminal.app도 충분하지만, 분할 창·검색·프로파일 저장이 필요한 순간 iTerm2로 넘어가게 됩니다. zsh 플러그인 몇 개만 붙여도 자동완성과 Git 상태 표시가 눈에 띄게 달라집니다.

### 단축키 충돌 확인
한글 입력 상태에서 단축키가 먹히지 않는 경우가 많습니다. 입력 소스를 영문으로 두고 테스트한 뒤 키 매핑을 정하는 것이 좋습니다.

## 체크리스트 3 — 에디터와 확장 프로그램

### VS Code 기본 세팅
- settings.json을 Git으로 관리하면 새 장비에서 복원이 빠릅니다.
- 확장은 Prettier, ESLint, GitLens 정도만 먼저 깔고 필요할 때 추가합니다.
- 원격 개발(Remote-SSH, Dev Containers)을 쓸 계획이면 초반에 설정해 두는 편이 낫습니다.

### 폰트와 테마
D2Coding, JetBrains Mono 같은 고정폭 폰트를 지정하면 눈 피로가 줄어듭니다. 한글과 코드가 섞이는 프로젝트라면 한글 글리프가 포함된 폰트를 고르세요.

## 체크리스트 4 — 보안과 백업

### Gatekeeper와 출처 확인
서명되지 않은 앱은 실행이 차단됩니다. 시스템 설정 → 개인정보 보호 및 보안에서 예외를 허용하기 전에, 배포처가 공식인지 반드시 확인합니다.

### Time Machine과 Git 원격 저장소
로컬 설정 파일은 대부분 Git으로 관리하지만, SSH 키와 인증서는 별도 백업이 필요합니다. `~/.ssh` 폴더를 암호화해 보관해 두면 재설치 때 시간이 크게 줄어듭니다.

한 가지 아쉬운 점은 각 도구의 최신 버전 변경 이력까지는 다루지 않는다는 것입니다. 설치 후에는 반드시 공식 릴리스 노트를 한 번 확인하는 습관을 권합니다.

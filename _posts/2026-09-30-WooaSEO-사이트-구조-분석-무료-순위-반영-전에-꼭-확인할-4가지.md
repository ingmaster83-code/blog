## 사이트 구조가 무너지면 생기는 일

검색엔진은 페이지 하나만 보지 않습니다. 사이트 전체의 링크 흐름, 디렉터리 깊이, 중복 URL, 색인 가능 여부를 함께 평가합니다. 이 중 하나라도 어긋나면 새로 쓴 글이 며칠씩 색인되지 않거나, 엉뚱한 페이지가 대표 URL로 잡히는 일이 생깁니다. 문제는 이런 오류가 눈에 보이지 않는다는 점입니다. 그래서 구조 분석을 주기적으로 돌려야 합니다.

### 1단계: 분석할 주소 입력

메인 페이지 주소를 입력하고 실행하면 사이트 내부 링크를 따라가며 페이지 목록과 연결 상태를 수집합니다. 이때 홈이 아닌 특정 카테고리 주소를 넣으면 해당 영역만 집중적으로 볼 수도 있습니다.

### 2단계: 크롤링 오류 페이지 확인

404, 500 같은 응답 코드가 찍힌 페이지를 먼저 봅니다. 내부 링크가 깨진 상태로 남아 있으면 검색 로봇의 크롤링 예산이 낭비되고, 사용자 이탈도 함께 늘어납니다. 오류 페이지는 삭제하거나 원래 주소로 301 리디렉션을 걸어 정리합니다.

### 3단계: 내부링크 깊이와 고아 페이지 점검

홈에서 몇 번의 클릭으로 도달할 수 있는지(링크 깊이)와, 어디서도 링크되지 않은 고아 페이지가 있는지 확인합니다. 깊이가 4단계를 넘어가면 검색 로봇의 접근 우선순위가 떨어지므로, 주요 글은 카테고리나 관련 글 링크로 더 가까이 끌어올리는 것이 좋습니다. 고아 페이지는 사이트맵에 등록하거나 본문 내 링크로 연결해줍니다.

### 4단계: 중복 URL과 색인 상태 정리

같은 내용이 여러 주소로 접근되는 경우(예: 파라미터가 붙은 주소, http와 https 혼용) 정규 URL을 지정해 하나로 통일합니다. 검색엔진 색인에서 빠진 페이지가 있다면 robots.txt나 메타 로봇 태그 설정을 다시 확인해야 합니다.

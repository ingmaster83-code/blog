## 기능 상세: 확인해야 할 4가지 항목

### 1. IP 주소와 서브넷 마스크

가장 먼저 볼 것은 IP 주소다. 정상 할당이면 192.168.x.x나 10.x.x.x 형태가 뜬다. 만약 **169.254.x.x**로 시작한다면 DHCP 서버, 즉 공유기가 주소를 못 준 상태다. 이 경우 공유기 전원과 랜선 접촉부터 확인해야 한다. 서브넷 마스크는 보통 255.255.255.0이며, 이 값이 어긋나면 같은 공유기에 물려 있어도 서로 통신이 안 된다.

### 2. 기본 게이트웨이

게이트웨이는 외부 인터넷으로 나가는 출구 주소다. 여기가 비어 있거나 공유기 IP와 다르면 인터넷은 절대 연결되지 않는다. 내부 파일 공유나 프린터 연결만 될 때 대부분 이 항목이 원인이다.

### 3. DNS 서버

DNS는 도메인을 IP로 바꿔주는 역할을 한다. 게이트웨이는 정상인데 특정 사이트만 안 열리거나 로딩이 유독 느리다면 DNS를 의심해야 한다. 통신사 기본 DNS 대신 8.8.8.8(구글)이나 1.1.1.1(클라우드플레어)로 바꾸는 것만으로 해결되는 경우가 적지 않다.

### 4. 연결 상태 진단

여기까지 정상인데도 안 되면 실제 응답이 오가는지 확인해야 한다. 게이트웨이로 핑을 쏴보고, 그다음 외부 주소로 핑을 쏴본다. 앞은 되는데 뒤가 안 되면 공유기 문제, 둘 다 안 되면 PC 설정 문제로 범위가 좁혀진다.

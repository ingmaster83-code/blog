## 발표 30분 전, 변수 이름 하나 때문에 막힌 이야기

WooaDev 문자열 변환 무료 방법을 찾는 사람은 대개 급하다. 필자도 팀 과제 발표를 30분 앞두고 자바스크립트 코드의 변수명을 전부 스네이크케이스로 바꿔야 했던 적이 있다. 손으로 하나씩 고치다가는 시간이 남지 않을 게 뻔했고, 검색창에 "문자열 변환"을 치고 들어간 사이트가 바로 여기였다.

결론부터 말하면 이 도구는 설치도, 회원가입도 필요 없다. 브라우저 창에 텍스트를 붙여넣고 형식을 고르면 끝이다. 아래에서 실제로 써본 순서를 그대로 정리한다.

## WooaDev 문자열 변환 도구, 어떤 기능이 들어있나

[WooaDev 무료로 사용하기](https://wooadev.wooahouse.com)에 접속하면 텍스트 입력창과 변환 옵션이 한 화면에 모여 있다. 별도 프로그램 설치 없이 온라인에서 바로 처리되는 방식이라, 학교 실습실 PC처럼 권한이 막힌 환경에서도 문제없이 돌아간다.

주요 기능은 크게 네 갈래다.

- 대소문자 변환: 전체 대문자, 전체 소문자, 첫 글자만 대문자
- 표기법 변환: 카멜케이스, 파스칼케이스, 스네이크케이스, 케밥케이스
- 공백·줄바꿈 정리: 중복 공백 제거, 빈 줄 삭제
- 인코딩 처리: URL 인코딩과 디코딩, 특수문자 이스케이프

코딩 과제를 하다 보면 API 응답값을 그대로 붙여넣고 정리해야 할 일이 많은데, 이런 잡다한 처리를 한 사이트에서 끝낼 수 있다는 게 가장 큰 장점이다.

### 변수명 표기법, 헷갈릴 때 기준

| 표기법 | 예시 | 주 사용처 |
|---|---|---|
| 카멜케이스 | userName | 자바, 자바스크립트 |
| 파스칼케이스 | UserName | 클래스명, 리액트 컴포넌트 |
| 스네이크케이스 | user_name | 파이썬, DB 컬럼 |
| 케밥케이스 | user-name | CSS 클래스, URL 슬러그 |

발표 직전에 이 표를 머릿속에 넣어두면 "왜 이 이름만 규칙이 다르냐"는 질문을 피할 수 있다.

## 단계별 사용법

### 1단계: 변환할 텍스트 붙여넣기

왼쪽 입력창에 원본 문자열을 넣는다. 변수명 목록이든, 로그에서 긁어온 URL이든 상관없다. 여러 줄을 한꺼번에 넣어도 줄 단위로 각각 처리된다.

### 2단계: 원하는 변환 형식 선택

상단 옵션에서 카멜케이스, 스네이크케이스 등 원하는 항목을 클릭한다. 선택과 동시에 결과가 갱신되는 구조라 별도 실행 버튼을 누를 필요가 없다.

### 3단계: 결과 복사 후 코드에 반영

오른쪽 결과창의 복사 버튼을 누르고 편집기로 돌아간다. 이때 원본을 지우기 전에 한 번 더 눈으로 대조하는 습관을 들이면 좋다.

## 쓰기 전에 알아둘 주의사항

첫째, 자동 정리 기능이 켜져 있으면 의도한 공백까지 사라질 수 있다. 들여쓰기가 중요한 코드를 통째로 넣을 때는 옵션을 먼저 확인하자.

둘째, 변환은 입력한 텍스트 기준으로만 이루어진다. 이미 저장된 파일을 불러와 고치는 방식이 아니므로, 원본 파일은 반드시 따로 백업해 둬야 한다.

셋째, 아주 긴 문서를 한 번에 넣으면 브라우저가 버벅일 수 있다. 수천 줄 단위라면 문단을 나눠 여러 번 처리하는 편이 빠르다.

## 결국 급할 때 빛을 보는 도구

정리하자면 WooaDev 문자열 변환 무료 방법의 핵심은 세 가지다. 설치가 없고, 회원가입이 없고, 결과가 즉시 나온다. 과제 마감이나 코드 리뷰 직전처럼 시간이 없는 순간에 특히 유용하다.

## 사용법 3단계 — 파일 올리고, 순서 맞추고, 저장

### 1단계: 파일 업로드

페이지에 들어가 PDF 합치기 메뉴를 선택한 뒤, 합칠 파일을 끌어다 놓거나 파일 선택 버튼으로 추가한다. 여러 개를 한 번에 올릴 수 있고, 추가한 파일은 목록 형태로 표시된다.

### 2단계: 순서 정리와 불필요 페이지 제거

여기가 실제로 결과물 품질을 좌우하는 단계다. 목록에서 파일 순서를 위아래로 옮겨 원하는 배열로 맞춘다. 예를 들어 표지 → 본문 → 첨부 순으로 제출해야 한다면 이 순서를 반드시 여기서 잡아야 한다. 잘못 올린 파일은 삭제하고 다시 추가하면 된다.

페이지 단위로 필요 없는 장을 빼고 싶다면 병합 전에 해당 파일을 먼저 분할하거나 페이지 삭제 기능을 이용하는 편이 깔끔하다.

### 3단계: 병합 실행 후 저장

합치기 버튼을 누르면 처리 결과가 생성된다. 다운로드 버튼으로 저장하면 끝이다. 저장된 파일을 열어 첫 페이지와 마지막 페이지, 그리고 중간 연결 부분이 의도대로 이어졌는지 확인하는 습관을 들이면 좋다.

## 주의사항 — 여기서 실수하면 다시 해야 한다

**첫째, 원본 파일명을 미리 정리해 두자.** 파일이 10개를 넘어가면 목록에서 어떤 파일이 어떤 내용인지 헷갈린다. 업로드 전에 파일명을 "01_표지", "02_본문"처럼 바꿔두면 순서 실수를 줄일 수 있다.

**둘째, 스캔 문서는 방향을 먼저 확인하자.** 스캐너에서 삐뚤게 들어간 페이지가 섞여 있으면 병합 후 문서 전체가 어색해진다. 병합 전에 회전 기능으로 방향을 맞추는 편이 낫다.

**셋째, 암호가 걸린 PDF는 먼저 해제해야 한다.** 비밀번호가 설정된 파일은 병합 과정에서 오류가 나거나 해당 페이지만 누락될 수 있다.

**넷째, 용량을 미리 가늠하자.** 원본 해상도를 유지한 채 합치면 용량은 사실상 더해진다. 메일 첨부 제한이 10MB나 25MB라면 병합 후 압축까지 염두에 두는 게 안전하다.

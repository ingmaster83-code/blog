## WooaColor 그라데이션 만들기, 왜 CSS를 직접 안 짜도 될까

WooaColor 그라데이션 만들기는 색상 코드를 몰라도 슬라이더 몇 번으로 배경 CSS를 뽑아내는 방식이다. 예전에는 `linear-gradient(90deg, #ff7e5f, #feb47b)` 같은 코드를 손으로 치고, 브라우저를 새로고침하며 색을 맞췄다. 지금은 그 과정을 도구가 대신한다.

## 주요 기능 상세

### 1. 색상 정지점과 색상 선택

색상 바를 클릭하면 정지점이 추가된다. 각 정지점마다 색상 피커로 HEX 값을 지정하거나, 색상환에서 직접 찍을 수 있다. 두 색만 쓰는 단순 그라데이션부터 다섯 색 이상의 다중 그라데이션까지 한 화면에서 처리된다.

### 2. 각도와 방향 제어

`linear-gradient`의 각도 값을 슬라이더로 조절한다. 0도는 아래에서 위, 90도는 왼쪽에서 오른쪽이다. 숫자를 외울 필요 없이 슬라이더를 움직이면 미리보기 박스가 실시간으로 바뀐다.

### 3. CSS 코드 자동 생성과 복사

설정이 끝나면 하단에 완성된 CSS 코드가 뜬다. 복사 버튼 한 번으로 클립보드에 들어간다. `background` 속성에 그대로 붙여넣으면 끝이다. 별도 변환 과정이 없다.

### 4. 실시간 미리보기

색상·각도·정지점 위치를 바꿀 때마다 미리보기 영역이 즉시 갱신된다. 저장 버튼을 누를 필요가 없어서 "일단 해보고 결정"하는 작업 흐름에 맞다.

## 실제로 써본 후기

### CSS를 직접 짤 때와 비교

직접 코딩하면 색상 코드를 검색하고, 각도를 머릿속으로 상상하고, 결과를 확인하려면 에디터와 브라우저를 오가야 한다. WooaColor는 그 왕복을 없앤다. 특히 색감을 "조금 더 따뜻하게" 같은 모호한 요청을 받았을 때 차이가 크다. 슬라이더를 몇 번 밀면 답이 나온다.

### 아쉬웠던 점

conic-gradient(원뿔형)는 별도 지원이 없다. 파이 차트 느낌의 배경이 필요하면 생성된 linear 코드를 참고해 수치만 직접 바꿔야 한다. 또 색상 정지점의 위치를 퍼센트로 정밀 입력하는 기능은 없어서, 마우스로 드래그해 맞춰야 한다.

### 누구에게 맞는가

- 급하게 랜딩 페이지 배경을 만들어야 하는 실무자
- CSS를 배우는 중이라 결과를 눈으로 확인하고 싶은 입문자
- 색 조합 시안을 여러 개 비교해야 하는 디자이너

반대로 픽셀 단위 정밀 제어가 필요한 프로덕션 작업이라면 포토샵이나 피그마가 낫다.

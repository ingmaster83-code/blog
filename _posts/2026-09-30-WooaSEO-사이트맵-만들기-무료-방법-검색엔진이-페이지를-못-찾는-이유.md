## WooaSEO 사이트맵 만들기 무료 방법, 왜 이걸 모르면 손해인가

블로그 글을 100개 넘게 썼는데 구글 서치 콘솔에 등록된 페이지는 12개뿐인 상황을 겪어본 적 있는가. 대부분 사이트맵을 아예 만들지 않았거나, 만들어도 형식이 틀려 검색엔진이 읽지 못한 경우다. WooaSEO 사이트맵 만들기 무료 방법은 이 문제를 브라우저 안에서 3분 안에 정리해준다.

사이트맵(Sitemap)은 검색엔진에게 "우리 사이트에 이런 주소들이 있다"고 알려주는 목록 파일이다. 구글은 사이트맵이 없어도 크롤링을 하지만, 신규 사이트나 구조가 복잡한 사이트는 발견 속도가 눈에 띄게 느려진다. 특히 티스토리·워드프레스가 아닌 직접 만든 HTML 사이트라면 사실상 필수다.

## 주요 기능 — 사이트맵 생성 절차

### 1단계: URL 목록 입력

텍스트 상자에 사이트 주소를 한 줄에 하나씩 붙여넣는다. 엑셀에서 복사해도 줄바꿈만 유지되면 그대로 인식된다. 최대 500개 URL까지 한 번에 처리된다. 500개를 넘으면 500개 단위로 나눠서 `sitemap1.xml`, `sitemap2.xml`처럼 분할 생성하는 것이 안전하다.

### 2단계: 옵션 설정

- **우선순위(Priority)**: 0.0~1.0 사이 값. 메인 페이지는 1.0, 일반 글은 0.6~0.8이 무난하다. 모든 페이지를 1.0으로 넣는 것이 가장 흔한 실수인데, 이렇게 하면 우선순위 정보 자체가 무의미해진다.
- **변경 빈도(Changefreq)**: daily, weekly, monthly 중 선택. 공지사항은 weekly, 블로그 글은 monthly가 현실적이다.
- **최종 수정일(Lastmod)**: 날짜를 비워두면 검색엔진이 "언제 바뀐 건지 모르는 페이지"로 취급해 재방문 주기가 늘어난다.

### 3단계: XML 다운로드 및 업로드

생성 버튼을 누르면 `sitemap.xml` 파일이 즉시 다운로드된다. 이 파일을 사이트 루트 디렉터리(예: `example.com/sitemap.xml`)에 업로드한다. 티스토리는 `[https://내블로그.tistory.com/sitemap.xml`이](https://내블로그.tistory.com/sitemap.xml`이) 기본 제공되므로 별도 업로드가 필요 없다.

### 4단계: 검색엔진에 제출

구글 서치 콘솔 → 색인 → Sitemaps 메뉴에서 주소를 입력하고 제출한다. 네이버 서치어드바이저도 요청 → 사이트맵 제출 경로가 동일하다. 제출 후 "성공" 상태가 뜨기까지 보통 1~3일 걸린다.

## 활용 팁 — 실패를 줄이는 4가지

### robots.txt에 사이트맵 주소 명시

`sitemap.xml`을 업로드만 하고 끝내면 검색엔진이 못 찾을 수 있다. robots.txt 파일 맨 아래에 `Sitemap: [https://example.com/sitemap.xml`](https://example.com/sitemap.xml`) 한 줄을 추가하면 발견 확률이 크게 올라간다.

### noindex 페이지는 넣지 않는다

로그인 페이지, 장바구니, 검색 결과 페이지처럼 색인되면 안 되는 주소를 사이트맵에 넣으면 서치 콘솔에 "색인되지 않음" 경고가 쌓인다. 이 경고가 많아지면 정상 페이지 크롤링 예산까지 잡아먹는다.

### 301 리다이렉트 주소는 원본으로 교체

`[http://`](http://`) 버전과 `[https://`](https://`) 버전을 동시에 넣으면 중복 URL로 판정된다. 최종 목적지 주소 하나만 넣어야 한다.

### 갱신 주기를 지킨다

새 글을 쓸 때마다 사이트맵을 다시 생성해야 하는 것은 아니다. 구글은 사이트맵 자체를 주기적으로 다시 읽기 때문에, 월 1회 정도 재생성해서 덮어쓰는 것으로 충분하다.

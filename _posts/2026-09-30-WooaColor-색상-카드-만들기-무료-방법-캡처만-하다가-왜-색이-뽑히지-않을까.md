## WooaColor에서 색상 카드 만들기 무료 방법

### 1단계 — 화면에서 색 직접 뽑기
화면에 띄운 이미지나 웹페이지에서 원하는 색 위에 커서를 올리면 HEX, RGB, HSL 값이 동시에 뜹니다. 캡처 후 눈대중으로 고르는 방식과 달리, 원본 픽셀 값을 그대로 읽어오기 때문에 색이 틀어지지 않습니다.

### 2단계 — 팔레트로 묶어 카드 형태로 정리
뽑은 색을 하나씩 메모하는 대신 팔레트에 담으면 카드처럼 나란히 배치됩니다. 메인 컬러 1개, 서브 컬러 2개, 배경용 톤 1개 식으로 역할을 나눠 두면 회의 자료에 그대로 붙이기 좋습니다.

### 3단계 — 코드 값으로 복사해 쓰기
카드에 표시된 값을 클릭하면 클립보드에 복사됩니다. CSS 변수 형태로 정리해두면 다음 프로젝트에서 `--main-color` 한 줄만 바꿔도 전체 톤이 맞춰집니다. 색상 팔레트를 코드로 관리하는 습관이 들면, 매번 색을 다시 찾는 일이 줄어듭니다.

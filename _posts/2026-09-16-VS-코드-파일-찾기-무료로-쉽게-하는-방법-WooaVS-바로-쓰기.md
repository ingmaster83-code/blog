## VS 코드 파일 찾기, 왜 이렇게 헤매기 쉬울까

VS Code는 기본적으로 파일 탐색기(Explorer)와 검색(Search) 패널을 제공합니다. 그런데 초보자 입장에서는 세 가지가 헷갈립니다. 첫째, 파일명 검색인지 내용 검색인지 구분이 안 됩니다. 둘째, node_modules 같은 폴더까지 뒤져서 결과가 수천 개로 쏟아집니다. 셋째, 브라우저에서 급하게 코드를 확인할 때는 VS Code를 열 수 없습니다.

이때 필요한 개념이 바로 **파일명 검색(Quick Open)**, **전체 텍스트 검색**, **검색 제외 필터**, **정규식 검색**, **작업 영역(Workspace) 범위 지정**입니다. 이 다섯 가지만 익혀도 검색 속도가 체감상 두세 배는 빨라집니다.

### 단축키부터 정리하기

- **Ctrl+P** (맥: Cmd+P): 파일명으로 바로 열기. 가장 많이 쓰는 VS 코드 파일 찾기 단축키입니다.
- **Ctrl+Shift+F** (맥: Cmd+Shift+F): 프로젝트 전체에서 텍스트·코드 검색.
- **Ctrl+Shift+E**: 탐색기 패널로 즉시 이동.
- **F12**: 함수 정의 위치로 점프.

### 검색이 느릴 때 체크할 것

1. `files.exclude` 설정에 `node_modules`, `dist`, `.next` 추가
2. 검색 패널의 `files to exclude` 칸에 빌드 산출물 경로 입력
3. 검색 범위를 `./` 전체가 아니라 특정 폴더로 좁히기
4. 대소문자 구분(Match Case)과 정규식(Use Regex) 토글 상태 확인

## 맥 캡처 저장이 안 될 때, 재부팅부터 하는 게 맞을까

WooaMac 맥 캡처 저장 방법을 찾는 사람 대부분은 이미 단축키를 눌러본 상태입니다. 화면은 잠깐 깜빡였는데 파일이 안 보이거나, 캡처 자체가 먹통이 된 상황이죠. 이때 재부팅부터 하면 대개 해결되지 않습니다. 원인은 대부분 저장 경로, 권한, 단축키 충돌 세 가지 중 하나입니다.

이 글은 그 세 가지를 비교 순서대로 짚어보고, 브라우저에서 바로 캡처와 저장을 끝내는 방법도 함께 다룹니다. 비교 기준은 "얼마나 빨리 원인을 특정할 수 있는가"입니다.

## 기본 캡처 단축키와 저장 위치부터 비교

### 단축키별 저장 방식 차이
- Shift + Command + 3 : 전체 화면, 즉시 파일 저장
- Shift + Command + 4 : 영역 지정, 즉시 파일 저장
- Shift + Command + 5 : 스크린샷 앱 실행, 저장 위치 선택 가능

여기서 중요한 건 앞의 두 단축키는 저장 위치를 묻지 않는다는 점입니다. 그래서 "캡처는 됐는데 어디 갔는지 모르겠다"는 상황이 생깁니다.

### 저장 위치 확인 순서
1. Finder를 열고 사이드바의 '데스크탑' 선택
2. Command + Shift + G 로 `~/Desktop` 직접 입력
3. 스크린샷 앱(Shift + Command + 5) 실행 후 '옵션' 메뉴에서 저장 위치 확인

iCloud 데스크탑 동기화가 켜져 있으면 로컬 데스크탑 폴더와 실제 저장 위치가 달라 보일 수 있습니다. 이 경우 Finder 사이드바의 iCloud 항목까지 확인해야 합니다.

## 캡처가 아예 안 될 때 확인할 권한 설정

### 화면 기록 권한
macOS Ventura 이후 버전에서는 화면 기록 권한이 별도로 관리됩니다. 시스템 설정 → 개인정보 보호 및 보안 → 화면 기록에서 사용 중인 앱이 허용되어 있는지 확인하세요. 이 항목이 꺼져 있으면 캡처 도구가 실행되어도 빈 화면만 저장됩니다.

### 데스크탑 폴더 접근 권한
파일 및 폴더 항목에서 데스크탑 접근이 차단되어 있으면 캡처 저장이 조용히 실패합니다. 오류 메시지조차 뜨지 않기 때문에 놓치기 쉬운 부분입니다.

## 실무에서 자주 쓰는 활용 팁

### 캡처 후 바로 편집까지 끝내는 순서
1. Shift + Command + 5로 스크린샷 앱 실행
2. 옵션에서 저장 위치를 고정 (매번 묻지 않도록)
3. 캡처 후 우측 하단 썸네일 클릭

썸네일이 사라지기 전에 클릭하면 별도 편집 앱을 열 필요가 없습니다. 이 흐름을 익혀두면 캡처 → 저장 → 편집에 걸리는 시간이 눈에 띄게 줄어듭니다.

### 파일명 규칙으로 정리하기

### 클립보드로 바로 붙여넣기
Control 키를 함께 누르면 파일로 저장되지 않고 클립보드에만 들어갑니다. 메신저나 문서에 바로 붙여넣을 때 유용하고, 데스크탑이 지저분해지지 않습니다.

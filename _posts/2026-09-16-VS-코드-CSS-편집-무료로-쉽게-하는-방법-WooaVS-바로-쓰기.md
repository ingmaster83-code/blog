## WooaVS 주요 기능 상세

### VS Code와 유사한 UI

WooaVS의 가장 큰 강점은 VS Code 사용자에게 익숙한 레이아웃이다. 사이드바, 탭, 상태바, 명령 팔레트 단축키까지 거의 동일하게 구성되어 있어서 VSCODE CSS 작업에 익숙한 개발자라면 학습 부담이 거의 없다.

### 실시간 CSS 미리보기

코드를 입력하는 즉시 오른쪽 패널에서 렌더링 결과가 반영된다. 별도로 브라우저를 새로고침하거나 Live Server 확장을 켤 필요가 없다는 점이 실무에서 체감상 가장 큰 장점이다.

### 자동 완성과 문법 강조

CSS 속성, 선택자, 색상 코드에 대한 자동 완성이 지원되며, 오타나 닫히지 않은 중괄호 같은 기본적인 문법 오류도 즉시 표시된다. 프론트엔드 입문자가 CSS 편집기를 처음 접할 때 특히 유용하다.

### 프로젝트 저장 및 불러오기

작업한 파일은 브라우저 세션에 유지되며, 필요할 경우 로컬로 내려받아 VS Code 프로젝트에 그대로 붙여넣을 수 있다. 반대로 기존 CSS 파일을 업로드해서 이어서 편집하는 것도 가능하다.

### 외부 라이브러리 연동

Bootstrap, Tailwind 같은 CSS 프레임워크의 CDN을 그대로 붙여 넣어 테스트할 수 있어, 실제 프로젝트에 적용하기 전 스타일 검증 용도로 쓰기 좋다.

## 폰트 폴더 위치, 매번 헤매는 이유

폰트 폴더 위치를 찾느라 윈도우 탐색기와 맥 파인더를 헤매본 경험, 한 번쯤 있을 겁니다. 디자이너나 개발자, 혹은 문서 작업이 잦은 직장인이라면 새 폰트를 설치하고 나서 "이 폰트가 어디에 저장됐지?" 하고 막막해지는 순간이 옵니다. 특히 윈도우는 사용자 설치 폰트와 시스템 폰트의 저장 경로가 다르고, 맥은 라이브러리 하위 폴더가 여러 개로 나뉘어 있어서 매번 경로를 검색하게 됩니다.

이 글에서는 폰트 저장 경로를 빠르게 파악하고, 폰트 자체의 정보까지 한 번에 확인할 수 있는 무료 도구 FontKit을 소개합니다. 설치 과정 없이 브라우저에서 바로 쓸 수 있어서 반복 작업 시간을 확실히 줄여줍니다.

## 주요 기능 한눈에 보기

### 드래그 한 번으로 폰트 정보 확인

폰트 파일을 화면에 끌어다 놓으면 폰트 패밀리명, 서브패밀리, 풀네임, 버전, 저작권 정보까지 한 화면에 정리됩니다. 여러 폰트를 동시에 올려 비교할 수도 있어서 프로젝트에 맞는 폰트를 고를 때 유용합니다.

### 폰트 저장 경로 확인과 정리의 출발점

FontKit에서 확인한 폰트 이름을 기준으로 윈도우 폰트 폴더(보통 C:\Windows\Fonts)나 맥 폰트 폴더(/Library/Fonts, ~/Library/Fonts)에서 해당 파일을 빠르게 찾을 수 있습니다. 폰트 이름을 모른 채 폴더만 뒤지는 것보다 훨씬 빠릅니다.

### 미리보기와 스타일 비교

폰트를 설치하지 않아도 미리보기로 실제 텍스트가 어떻게 보이는지 확인할 수 있습니다. 굵기, 기울기, 자간 차이를 비교하면서 문서나 디자인에 맞는 폰트를 즉시 판단할 수 있습니다.

### 3. 협업 시 폰트 정보 공유

외주 디자이너나 협업자에게 폰트를 전달할 때, 폰트 이름과 스타일 정보를 정확히 알려주면 상대방이 폰트 폴더 위치에서 헤매지 않습니다. FontKit 화면을 캡처해 공유하는 것만으로도 커뮤니케이션 비용이 줄어듭니다.

### 4. 클라이언트 PC에서 빠른 확인

다른 사람 PC에서 작업할 때 설치된 폰트를 확인하려면 폰트 폴더를 직접 여는 게 번거롭습니다. FontKit은 브라우저만 있으면 동작하므로 어떤 환경에서도 동일하게 폰트 정보를 확인할 수 있습니다.

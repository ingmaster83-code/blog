## 팀원 PC에서만 폰트가 깨지는 이유

FontKit 구글 폰트 사용법 무료 정보를 찾는 사람은 대부분 비슷한 상황이다. 내 노트북에서는 예쁘게 보이던 발표 자료가 회의실 PC에서 열면 기본 폰트로 바뀌어 있고, 줄 간격이 틀어져 레이아웃이 무너져 있다. 원인은 단순하다. 폰트 파일이 내 컴퓨터에만 설치되어 있었기 때문이다.

해결책은 두 갈래다. 폰트 파일을 통째로 첨부하거나, 웹에서 폰트를 불러오게 만드는 것이다. 앞은 용량이 커지고 뒤는 인터넷만 있으면 어디서든 동일하게 보인다. 후자를 가장 빠르게 처리하는 도구가 [FontKit 무료로 사용하기](https://fontkit.wooahouse.com)다.

## 구글 폰트를 웹에서 불러오는 원리

구글 폰트는 폰트 회사가 아니라 폰트를 모아 배포하는 저장소다. 여기서 폰트를 고르면 CSS 주소 한 줄이 나오고, 그 주소를 HTML에 넣으면 접속한 브라우저가 폰트를 내려받아 화면에 그린다. 내 PC에 설치된 폰트가 아니어도 표시가 된다는 뜻이다.

FontKit은 이 과정에서 필요한 코드를 대신 만들어 준다. 폰트 이름, 굵기, 문자 범위를 고르면 `<link>` 태그와 CSS `font-family` 선언이 한 번에 나온다. 구글 폰트 사이트를 오가며 굵기별 주소를 하나씩 복사하던 수고를 줄여 준다.

### 웹폰트와 로컬 폰트의 차이

- 로컬 폰트: 사용자 PC에 설치된 글꼴. 없는 PC에서는 대체 폰트로 표시된다.
- 웹폰트: 서버에서 내려받아 표시. 설치 여부와 무관하게 동일하게 보인다.
- 시스템 폰트: OS 기본 제공. 가장 빠르지만 디자인 선택지가 좁다.

## FontKit으로 구글 폰트 적용하는 순서

### 1단계 폰트 고르기

사이트에 접속하면 폰트 목록이 보인다. 한글 자료라면 Noto Sans KR이나 Nanum Gothic 계열을, 영문 위주라면 Roboto나 Inter를 고르면 무난하다. 제목용과 본문용을 나눠 두 개를 고르는 것도 방법이다.

### 2단계 굵기 선택하기

폰트마다 제공하는 굵기가 다르다. 보통 400(Regular)과 700(Bold)이면 충분하다. 굵기를 많이 추가할수록 내려받는 파일이 늘어나 페이지가 느려지므로 실제로 쓰는 굵기만 체크한다.

### 3단계 CSS 코드 복사하기

생성된 코드는 두 부분이다. `<head>` 안에 넣는 링크 태그와, 스타일시트에 넣는 `font-family` 선언이다. 블로그라면 스킨 편집의 CSS 항목, 노션 공개 페이지라면 커스텀 CSS 영역에 붙여 넣으면 된다.

### 4단계 적용 확인하기

브라우저를 새로고침하고 개발자 도구의 네트워크 탭을 열어 폰트 파일이 실제로 내려왔는지 확인한다. 시크릿 창에서 열어 보면 캐시 영향을 배제할 수 있어 확실하다.

## 놓치기 쉬운 주의사항

### 서브셋을 지정하지 않으면 느려진다

한글 폰트는 글자 수가 만 자를 넘는다. 전체 문자를 다 받으면 파일 하나가 수 MB에 달한다. 구글 폰트 주소에 `&subset=korean` 같은 서브셋 옵션이나 `text=` 파라미터를 붙이면 필요한 글자만 받아 속도가 크게 준다. FontKit에서 옵션을 켜 두면 이 부분이 자동으로 반영된다.

### 라이선스는 폰트마다 다르다

구글 폰트 대부분은 상업적 사용이 가능하지만 전부는 아니다. 인쇄물이나 상업용 콘텐츠에 쓸 때는 폰트 상세 페이지의 라이선스 항목을 한 번 확인하는 습관이 필요하다.

### 오프라인 환경에서는 표시되지 않는다

웹폰트는 이름 그대로 웹에서 받아온다. 인터넷이 끊긴 상태에서는 대체 폰트로 표시되므로, 오프라인 발표가 예정되어 있다면 폰트 파일을 직접 설치하거나 PDF로 변환해 두는 편이 안전하다.

### 폰트를 너무 많이 쓰면 통일성이 깨진다

한 문서에 세 가지 이상 폰트를 섞으면 산만해 보인다. 제목용 하나, 본문용 하나 정도로 제한하는 것이 보기에도, 로딩 속도에도 낫다.

## 정리

발표 자료나 블로그에서 폰트가 깨지는 문제는 폰트 파일을 함께 들고 다니는 대신 웹에서 불러오게 만드는 것으로 대부분 해결된다. FontKit 구글 폰트 사용법 무료 도구를 쓰면 폰트 선택부터 CSS 코드 생성까지 한 화면에서 끝나고, 서브셋 옵션까지 챙길 수 있어 로딩 속도 문제도 함께 줄어든다. 다음에 회의실 PC에서 자료가 무너지는 일이 생기면 [FontKit 무료로 사용하기](https://fontkit.wooahouse.com)에서 코드 한 줄을 뽑아 두는 것으로 시작해 보자.
